## Native Bridge Features

The native bridge provides a set of powerful features to enhance your desktop app experience by integrating deeply with the operating system.

<div style="display: grid; grid-template-columns: repeat(2, 1fr); gap: 1.5rem;">

  <div>

  **Notifications**  
  Manage system notifications seamlessly.

  </div>

  <div>

  **Badges**  
  Control app badges for user alerts.

  </div>

  <div>

  **Tray Integration**  
  Add your app to the system tray for quick access.

  </div>

  <div>

  **Menu Integration**  
  Customize system menus with app-specific options.

  </div>

  <div>

  **File System**  
  Access and manage the isolated file system securely, both temporary and permanent.

  </div>

  <div>

  **Shortcuts**  
  Register global shortcuts for enhanced user control.

  </div>

  <div>

  **Deep Links**  
  Handle custom protocol links efficiently.

  </div>

  <div>

  **Events**  
  Manage window and system events effectively.

  </div>

  <div>

  **Files**  
  Handle file operations and dialogs natively.

  </div>

  <div>

  **Drag & Drop**  
  Enable drag and drop interactions within your app.

  </div>

  <div>

  **WASM Plugins**  
  Extend functionality with sandboxed WebAssembly plugins.

  </div>

  <div>

  **Network**  
  Monitor and control network activities.

  </div>

  <div>

  **Window**  
  Manage window states and behaviors programmatically.

  </div>

  <div>

  **Autostart**  
  Configure your app to start automatically on system boot.

  </div>

</div>
